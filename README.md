# Korrekturassistent

Lokaler Arbeitsbereich für anonymisierte, OCR-verarbeitete Klausuren.

## Arbeitsablauf

1. Neues Klausurprojekt anlegen und Aufgabenstellung sowie Erwartungshorizont verknüpfen.
2. Eine oder mehrere anonymisierte OCR-PDFs laden.
3. Korrekturvorschlag für eine Klausur erzeugen.
4. Der Korrekturarbeitsplatz öffnet sich automatisch: links eine einzelne A4-PDF-Seite, rechts die Korrekturen dieser Seite.
5. Korrekturhinweis auswählen, Punkte und Begründung ändern oder im zugehörigen Chat diskutieren.
6. Optional eine Kommentar-PDF exportieren. Die ursprünglichen Seiten bleiben unverändert; Hinweise liegen als eigene Kommentar-Ebene vor.

Projektdateien und Chat-Verläufe können gespeichert und archiviert werden.
